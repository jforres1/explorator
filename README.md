# EXPLORATOR

ABSTRACT
Environmental Design for computer games, graphics, and animation is a time consuming and difficult task. There are many different approaches to Environmental Design, but for applications where it is not feasible to design by hand a procedural generation algorithm is often used. However, it is difficult to maintain artistic and developmental control over many common types of procedural generation. One commonly used algorithm for procedural generation is Wave Function Collapse. This algorithm uses a set of tiles who each contain information about what tiles they are allowed to have placed next to them. This project extends the Wave Function Collapse algorithm to read information from a provided image, and modifies the generation to more closely match the image. It achieves this by using soft-constraints to adjust the placement of tiles without creating contradictions. Explorator is a project that balances the constraints of speed, reliability, and developmental control in the procedural generation process.
